# SupportHub

En tant que collaborateur, je veux créer une demande avec un titre
pour signaler un problème informatique.

## Critères d’acceptation

1. Un titre vide ou composé uniquement d’espaces est refusé.
2. Une demande créée avec un titre valide conserve ce titre.
3. Toute nouvelle demande possède le statut "Ouverte".
